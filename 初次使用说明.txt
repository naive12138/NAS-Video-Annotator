NAS 视频内容分析与标注 —— 初次使用说明
========================================================

一、这个软件是做什么的
    对电脑 / 局域网 NAS 里的视频做本地 AI 内容分析（场景、人数、题材、剧情概括），
    并把结果自动写回：本地视频写到同名 .nfo 或 简介xxx.txt，Jellyfin 视频更新到简介栏。
    全程本地运行，视频内容不上传任何云端。

二、文件夹结构（重要！）
    NAS-Video-Annotator.exe  和  _internal 文件夹  必须放在一起，缺一不可。
    首次运行后，会在 exe 旁边自动生成一个 data 文件夹（配置、数据库、缓存都在里面）。
    把整个 NAS-Video-Annotator 文件夹拷到别的电脑也能直接用。

三、使用前需要自备
    1) 本地大模型服务（二选一）
       - Ollama（推荐）：装好后用命令拉取模型，例如：
           ollama pull qwen2.5vl:7b   （视觉模型）
           ollama pull qwen2.5:7b     （文本模型）
       - llama.cpp / LM Studio 等（OpenAI 兼容接口，端口通常 8080 / 1234）
    2) ffmpeg / ffprobe
       - 可在软件设置页点“一键下载 FFmpeg”；
       - 或手动把 ffmpeg.exe、ffprobe.exe 放到 exe 同目录，或 data\bin\ 里。
    3) （可选）Jellyfin 服务器地址 + API Key（只有用 Jellyfin 源时才需要）

四、第一步：设置
    1. 双击 NAS-Video-Annotator.exe 启动
    2. 左侧点“设置”：
       - 服务地址：填模型服务地址
           Ollama 默认  http://127.0.0.1:11434
           llama.cpp 默认 http://127.0.0.1:8080
       - 点“获取模型”，下拉框里选视觉模型、文本模型
       - 点页面底部“测试”，确认各项都是 ✓ 就绪
       - 数据源选“本地路径”（选媒体根目录）或“Jellyfin”（填地址和 API Key）
    3. FFmpeg 区块：显示“✓ 已就绪”即可；显示“✗”就点“一键下载 FFmpeg”

五、第二步：分析视频
    1. 点“媒体库” → 点“刷新” → 勾选要分析的视频 → 点“加入分析队列”
    2. 点“日志”页可看到每个视频的实时进度条
    3. 分析完成后会自动写回：
       - 本地视频 → 同名 .nfo（没有 .nfo 就写 简介+视频名.txt）
       - Jellyfin 视频 → 自动更新 Jellyfin 的简介栏

六、查看和管理结果
    - “检索”页：按题材/人数/关键词搜索，可导出 JSON / CSV / Markdown
    - 检索页每行有 [回写] [删除] 按钮；左下角“清空全部标注”
    - 双击某一行可查看完整详情
    - “错误”页：查看失败原因（文字可选中复制），可“删除全部”

七、常见问题
    1. “获取模型”报 404 → 服务地址/端口填错，或该服务不是 Ollama（软件已兼容 OpenAI 接口）
    2. 分析报“找不到文件” → 视频路径问题；Jellyfin 源会走 API 流地址，无需挂载盘符
    3. ffmpeg 检测不到 → 放到 exe 同目录 或 data\bin\，再点“重新检测”
    4. 第一次转写会下载语音模型（约几百 MB），存放在 data\hf_cache\
    5. Jellyfin 拉取超时 → 检查地址、API Key，或库太大稍后再试

八、数据都在哪里
    全部在 exe 同目录的 data 文件夹内：config.json（配置）、nasva.db（数据库）、
    frames（帧缓存，分析完自动清理）、bin（ffmpeg）、hf_cache（转写模型）。
    不要删除 nasva.db 和 config.json，那是你的配置和成果。
